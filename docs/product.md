# Tallystick

## Проблема

Обычные заметки трудно организовать, а там, где организация сложна, записи
перестают вестись. Мессенджер решает запись: одна лента, пишешь не задумываясь.
Но в нём нет навигации: к записям не вернуться, их не отфильтровать, не разделить
по направлениям, а разнос по разным чатам — та же сложная организация.

Tallystick — одна лента всего, что записывается: мысли, еда, тренировки, заметки
по проектам. Поверх неё — лёгкая организация (типы, поля, проекты) и быстрая
гибкая навигация по всему этому.

## Для кого

Сейчас — для автора. Позже — для других людей. Решения принимаются по опыту
автора, не по воображаемому среднему пользователю.

## Принципы

- Записывать много и быстро, не задумываясь об организации. Скорость записи
  важнее структуры.
- Организация простая и необязательная в момент записи: тип, поля и проекты
  можно указать или изменить в любое время.
- Лента одна. Разделение записей — только фильтрами.
- Локальное приложение в первую очередь: работает на устройстве, без сервера
  и аккаунта.

## Чего продукт не делает

- Не задачник: нет сроков, напоминаний и отметок «выполнено».
- Нет системных типов: все типы создаёт пользователь.
- Нет нескольких лент.
- Время записи нельзя изменить.

## Продуктовые решения

### Лента и записи

- Лента упорядочена строго по времени добавления записи; это время неизменно.
- Запись: текст, вложения (фото, видео, файлы), значения полей своего типа,
  проекты, ответ на другую запись, актуальность.
- Неактуальная запись остаётся в ленте, но помечена; скрыть её можно только
  явным фильтром.

### Типы и поля

- У записи ровно один тип. При первом запуске есть один тип по умолчанию без
  полей; его можно править и удалять, но хотя бы один тип есть всегда.
- Виды полей: один из списка, несколько из списка, число (с необязательной
  единицей), строка. Все поля необязательны.
- При смене типа записи значения полей, которых нет в новом типе, теряются —
  после предупреждения.
- При удалении типа его записи переводятся в выбранный пользователем другой тип.

### Проекты

- Проект — метка записи с началом и концом. У записи может быть несколько
  проектов.
- Статусы: активный и завершённый. Даты начала и конца ставятся автоматически
  при смене статуса.
- Привязка записи к завершённому проекту автоматически возобновляет его; при
  возобновлении дата конца стирается, дата начала сохраняется.
- Смены статуса проекта отмечаются в ленте служебными отметками.
- Активных проектов много, поэтому они разложены по категориям, как папки
  в Телеграме. У проекта одна категория; при завершении она замораживается,
  при возобновлении проект возвращается в неё.

### Ответы

- Ответ — запись, привязанная к исходной записи. Под записью видны только её
  прямые ответы.
- Ответы на запись — та же хронология, ограниченная прямыми ответами на неё.
- В общей ленте ответ виден на своём месте с цитатой исходной записи.

### Навигация

- Ядро: фильтры (тип, проект, актуальность, период), поиск по тексту и условия
  по значениям полей.

## Открытые вопросы

- Синхронизация между устройствами.
- Поля-даты.
- Закреплённые ссылки на ленту с разными фильтрами.
