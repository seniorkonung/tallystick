# Языковые модели прямо из браузера через AI SDK

Чатам нужны языковые модели разных провайдеров, а у разведчика нет сервера.
Браузер обращается к провайдеру напрямую с ключом пользователя через Vercel AI
SDK: он даёт единый интерфейс к API Anthropic, OpenAI и совместимым с OpenAI,
потоковые ответы, цикл вызова инструментов и подтверждение вызовов. Провайдеры
с ключами хранятся в IndexedDB рядом с остальными данными.

## Рассмотренные варианты

- **Свой прокси-сервер с ключами.** Прячет ключ от страницы, но требует сервера
  и аккаунта, от которых приложение отказалось.
- **SDK каждого провайдера.** Разные форматы сообщений и свой цикл инструментов
  для каждого API.

## Последствия

- Ключ доступен любому скрипту страницы. Поэтому код, который пишет ассистент
  (будущие мини-приложения), работает только в песочнице без доступа к origin
  приложения.
- Anthropic принимает запросы из браузера только с заголовком
  `anthropic-dangerous-direct-browser-access`; провайдер без CORS для браузера
  не подключится.
