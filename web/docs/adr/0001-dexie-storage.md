# Хранение данных в IndexedDB через Dexie

Разведчику важна скорость разработки, а не масштаб: при десятках записей в день
объём за годы — десятки тысяч записей. Данные хранятся в IndexedDB через Dexie.
Компоненты читают их живыми запросами (`useLiveQuery`), без копии в отдельном
сторе. Фильтры, условия по полям и поиск по тексту выполняются на TypeScript по
записям в памяти; вложения лежат в отдельной таблице, чтобы лента не загружала
их в память.

## Рассмотренные варианты

- **SQLite в браузере** (sqlite-wasm в OPFS, в Web Worker), как в первом дизайне.
  Сильнее на сложных запросах и полнотекстовом индексе при сотнях тысяч записей,
  но требует воркера и SQL-слоя. Полнотекстовый поиск FTS5 без русской морфологии
  не превосходит поиск подстроки в памяти.

## Последствия

- Ограничения хранилища браузера те же, что были бы у SQLite: без разрешения на
  постоянное хранение браузер может удалить данные при нехватке места, а на iPhone
  данные надёжно живут только у приложения, установленного на экран «Домой».
