# Общее состояние интерфейса в Zustand

Данные живут в Dexie и читаются живыми запросами ([0001](0001-dexie-storage.md)),
поэтому стору остаётся только состояние интерфейса, нужное далёким друг от друга
компонентам: редактирование и ответ, выбор в панели ввода, активные фильтры. Оно
хранится в Zustand; состояние одного компонента остаётся в `useState`. Zustand
выбран, потому что код разведчика пишут агенты, а его небольшой и годами стабильный
API они знают надёжно.

## Рассмотренные варианты

- **Reatom 1000+.** Единая реактивная модель для асинхронных данных, форм и
  роутинга, но эти возможности не нужны, когда данными владеет Dexie. API новый
  и продолжает меняться, поэтому агенты путают его со старыми версиями.
- **React Context.** При таком объёме общего состояния даёт лишние перерисовки
  и вложенные провайдеры.
