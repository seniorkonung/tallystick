### Code navigation with Serena

Use the Serena MCP tools for working with code: symbol overview, symbol search, references, and symbol-level edits. Use grep, ls, and whole-file reads only for non-code files or when Serena cannot answer the question. If Serena tools are deferred, load them before starting work with code.
